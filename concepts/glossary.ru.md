# Глоссарий

| Термин | Значение |
|---|---|
| **DocHub** | Единое место документации проектов и слой координации ИИ-агентов и людей вокруг неё |
| **Core** | Репозиторий с концепцией, протоколом, правилами и скилом DocHub. Кода не содержит |
| **Хаб** | Git-репозиторий DocHub: конфигурация, wiki проектов и данные функций. Открывается в Obsidian как vault |
| **Wiki** | Своя документация проекта: `projects/<id>/wiki/`, хаб для неё источник истины |
| **Docs** | Внешняя документация проекта: `projects/<id>/docs/<папка>/`, только чтение, не в git хаба |
| **Источник** | Подключённый к проекту репозиторий: `projects.<id>.docs.<папка>` в конфигурации |
| **Паспорт** | `.source.yaml` в папке docs: репозиторий, ветка, коммит и время выгрузки |
| **Проект** | Зарегистрированный в хабе проект: wiki, подключённые docs, зоны, участники, функции |
| **Зона** | Путь внутри документации проекта с владельцами (`areas`). Пример: `wiki/mobile-app/` |
| **Владелец зоны** | Агент, который решает по предложениям в зоне и правит её документы в wiki |
| **Межпроектный контракт** | Документация, описывающая интерфейс между проектами. Хранится в wiki проекта источника как зона |
| **Агент** | Участник хаба с именем: ИИ-агент (сессия, инструмент) или человек |
| **Идентичность агента** | Имя агента, заданное в его окружении (`DOC_HUB_AGENT`, `--agent`), не в репозитории |
| **Участник** (`participant`) | Роль: читать, обсуждать, ставить отметки работы, смотреть изменения |
| **Читатель** (`reader`) | Роль: только читать |
| **Ограничение путями** | `members.<агент>.paths`: агент видит только эти пути документации проекта |
| **Функция** | Подключаемая к проекту возможность хаба: `discussions`, `changes`, `claims` |
| **Обсуждение** | Файл с вопросом, предложением или уведомлением и сообщениями участников |
| **Метка сообщения** | Строка `[время агент]`, с которой начинается сообщение в обсуждении; перед ней стоит разделитель `---` |
| **Итог** (`outcome`) | Краткое решение обсуждения; составляет общую память агентов |
| **Отметка просмотра** | Последние коммиты wiki и docs, изменения до которых агент видел (функция `changes`) |
| **Отметка работы** (claim) | «Работаю над …» с автором и сроком действия |
| **Манифест проекта** | `.doc-hub.json` в репозитории: какой хаб, какие проекты |
| **Конфигурация хаба** | `.doc-hub/config.yaml`: проекты, зоны, агенты, роли, функции |
| **Протокол** | Обязательные правила совместимости: файлы хаба, права, статусы, синхронизация. См. [protocol](../specifications/protocol.ru.md) |
| **Реализация** | Программа, работающая с хабом по протоколу: CLI, Web, сервис |
| **Эталонная реализация** | CLI `doc-hub` из репозитория `cli` |
| **Уровень работы** | Что стоит между агентом и файлами хаба: ядро, утилита, сервис. См. [levels](levels.ru.md) |
| **Скил** | Инструкция для агента, работающего с файлами хаба без утилиты |
| **uid** | ULID-идентификатор во frontmatter обсуждений. В документацию хаб его не добавляет |

# Глоссарий

| Термин | English | Значение |
|---|---|---|
| **DocHub** | DocHub | Единое место документации проектов и слой координации ИИ-агентов и людей вокруг неё |
| **Core** | Core | Репозиторий с концепцией, протоколом, правилами и скилом DocHub. Кода не содержит |
| **Хаб** | Hub | Git-репозиторий DocHub: конфигурация, wiki проектов и данные функций. Открывается в Obsidian как vault |
| **Wiki** | Wiki | Своя документация проекта: `projects/<id>/wiki/`, хаб для неё источник истины |
| **Docs** | Docs | Внешняя документация проекта: `projects/<id>/docs/<папка>/`, только чтение, не в git хаба |
| **Источник** | Source | Подключённая к проекту внешняя документация, локальная папка или репозиторий: `projects.<id>.docs.<папка>` в конфигурации |
| **Выгрузка** | Export | Копия внешней документации с зафиксированного коммита в `projects/<id>/docs/<папка>/`, а также операция, которая её делает |
| **Паспорт** | Passport | `.source.yaml` в папке docs: откуда и когда выгружено, для репозитория — ветка и коммит |
| **Виртуальный путь** | Virtual path | Путь документа внутри проекта: `wiki/…` или `docs/<папка>/…` |
| **Проект** | Project | Зарегистрированный в хабе проект: wiki, подключённые docs, зоны, участники, функции |
| **Зона** | Area | Путь внутри документации проекта с владельцами (`areas`). Пример: `wiki/mobile-app/` |
| **Владелец зоны** | Area owner | Агент, который решает по предложениям в зоне и правит её документы в wiki |
| **Межпроектный контракт** | Cross-project contract | Документация, описывающая интерфейс между проектами. Хранится в wiki проекта-владельца контракта как зона |
| **Проект-владелец контракта** | Contract owner project | Проект, в wiki которого хранится межпроектный контракт |
| **Агент** | Agent | Участник хаба с именем: ИИ-агент (сессия, инструмент) или человек |
| **Идентичность агента** | Agent identity | Имя агента, заданное на машине: явный параметр реализации, `DOC_HUB_AGENT` или `agent` локального манифеста |
| **Суффикс агента** | Agent suffix | Окончание имени для другого агента в том же проекте: `portal-tests`. Задаётся в `DOC_HUB_AGENT_SUFFIX` |
| **Базовый агент** | Base agent | Зарегистрированный агент, чьи роль, пути и владение наследует агент с суффиксом |
| **Участник** (`participant`) | Participant | Роль: читать, обсуждать, ставить отметки работы, смотреть изменения |
| **Читатель** (`reader`) | Reader | Роль: читать; пишет только свою отметку просмотра |
| **Администратор хаба** | Hub administrator | Человек с правом записи в репозиторий хаба; меняет конфигурацию. Отдельной роли в модели нет |
| **Ограничение путями** | Path restriction | `members.<агент>.paths`: агент видит только эти пути документации проекта |
| **Функция** | Feature | Подключаемая к проекту возможность хаба: `discussions`, `changes`, `claims` |
| **Обсуждение** | Discussion | Файл с вопросом, предложением или уведомлением и сообщениями участников |
| **Входящие** | Inbox | Обсуждения, где от агента ожидается реакция, см. [discussions](../specifications/features/discussions.ru.md#входящие) |
| **Метка сообщения** | Message mark | Строка `[время агент]`, с которой начинается сообщение в обсуждении; перед ней стоит разделитель `---` |
| **Итог** (`outcome`) | Outcome | Краткое решение обсуждения; составляет общую память агентов |
| **Отметка просмотра** | View mark | Последние коммиты wiki и docs, изменения до которых агент видел (функция `changes`) |
| **Отметка работы** (claim) | Claim | «Работаю над …» с автором и сроком действия |
| **Манифест проекта** | Project manifest | `.doc-hub.yaml` в корне репозитория, свой на каждой машине и не в git: разделы по хабам с проектами и именем агента по умолчанию |
| **Конфигурация хаба** | Hub configuration | `.doc-hub/config.yaml`: проекты, зоны, агенты, роли, функции |
| **Протокол** | Protocol | Обязательные правила совместимости: файлы хаба, права, статусы, синхронизация. См. [protocol](../specifications/protocol.ru.md) |
| **Реализация** | Implementation | Программа, работающая с хабом по протоколу: CLI, Web, сервис |
| **Утилита** | Utility | Реализация на машине агента, уровень 2 |
| **Эталонная реализация** | Reference implementation | CLI `doc-hub` из репозитория `cli` |
| **Уровень работы** | Work level | Что стоит между агентом и файлами хаба: ядро, утилита, сервис. См. [levels](levels.ru.md) |
| **Скил** | Skill | Инструкция для агента, работающего с файлами хаба без утилиты |
| **uid** | uid | ULID-идентификатор во frontmatter обсуждений. В документацию хаб его не добавляет |

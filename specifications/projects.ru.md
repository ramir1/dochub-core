# Проекты

## Что такое проект

**Проект** — зарегистрированная в хабе единица документации. Хаб знает о проекте:

| Параметр | Обязателен | Описание |
|---|:-:|---|
| идентификатор (`projects.<id>`) | да | `^[a-z0-9][a-z0-9-]*$`, уникален в хабе; совпадает с папкой `projects/<id>/` |
| `name` | да | Название |
| `docs.<папка>` | нет | Подключённая внешняя документация, см. [docs-sources](docs-sources.ru.md) |
| `owners` | да | Владельцы проекта по умолчанию — для путей, не попавших в зоны |
| `areas` | нет | Зоны и их владельцы |
| `members` | да | Агенты, их роли и ограничения путями, см. [access](access.ru.md) |
| `features` | нет | Включённые функции, см. [features](../concepts/features.ru.md) |

Схема — [hub-config](../schemas/hub-config.ru.md). Пока регистрация — ручная правка `.doc-hub/config.yaml`; команда `doc-hub project register` ещё не реализована.

Проект может иметь только wiki, только docs или и то и другое.

## Два вида документации

| | [Wiki](wiki.ru.md) | [Docs](docs-sources.ru.md) |
|---|---|---|
| Что это | Своя документация | Внешняя документация |
| Источник истины | Хаб | Репозиторий |
| Где лежит | `projects/<id>/wiki/` | `projects/<id>/docs/<папка>/` |
| В git хаба | Да | Нет |
| Правка | Obsidian, `doc-hub wiki write` | Только в репозитории |
| Требования хаба | Да | Нет |

Контракты и общие описания — в wiki; то, что меняется вместе с кодом, — в docs.

## Зоны

**Зона** — путь внутри документации (папка или файл) со своими владельцами:

```yaml
owners: [portal-backend]
areas:
  wiki/api:        { owners: [portal-backend] }
  wiki/ui:         { owners: [portal-frontend] }
  wiki/mobile-app: { owners: [portal-backend] }
```

- Документ относится к зоне с **самым длинным совпадающим** путём. Не попал ни в одну — к владельцам проекта (`owners`).
- **Владельцы зоны** решают по предложениям об изменении её документов и правят их в wiki.
- Зоны не ограничивают чтение и участие в обсуждениях — для этого есть `members.<агент>.paths`.

## Межпроектный контракт

Документация, описывающая интерфейс между проектами (пример — `mobile-app`), хранится **в wiki проекта источника** как зона. Агент проекта-получателя — участник проекта источника с ограничением `paths`: он читает контракт и обсуждает его, а правит владелец зоны. Контракт приходит с клоном хаба, доступ к коду источника не нужен.

## Отключение и удаление

Не специфицировано. Предложение: при отключении функции её данные остаются в хабе только для чтения; при удалении проекта папка `projects/<id>/` переносится в архив.

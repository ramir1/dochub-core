# Функция «Отметки работы»

**Ключ:** `claims` · **Статус:** черновик

Отвечает на вопрос: **кто сейчас работает над этим?** Нужна, когда параллельно работают несколько агентов (сессии по зонам, разные инструменты, разные машины), чтобы они не взялись за одно и то же.

Отметка — **предупреждение, а не блокировка**: хаб не может запретить правку репозитория.

## Модель

Отметка — файл `projects/<id>/claims/<агент>-<slug>.md`, пишет только сам агент. Схема — [schemas/claim](../../schemas/claim.ru.md).

| Свойство | Описание |
|---|---|
| `agent` | Кто работает |
| `paths` | Виртуальные пути документации (`wiki/…`, `docs/<папка>/…`) и, при желании, пути кода от корня репозитория проекта |
| `topic` | Что делается, одной строкой |
| `created` | Когда поставлена |
| `expires` | Когда истекает |
| `discussion` | Необязательно: связанное обсуждение |

Отметка **действует**, пока файл существует и `expires` не наступил. Истёкшие отметки игнорируются; удалить их может любой участник (исключение из правила «один файл — один автор»).

## Операции

| Операция | Кто | Что делает |
|---|---|---|
| поставить | `participant` | Создаёт файл. Перед этим проверить пересечения |
| продлить | автор | Меняет `expires` |
| снять | автор | Удаляет файл (история остаётся в git) |
| список | все с доступом | Действующие отметки, фильтр по путям |
| проверить пересечение | все | Есть ли действующие чужие отметки на пути, пересекающиеся с заданными |

Пути **пересекаются**, если один является префиксом другого (`wiki/api` и `wiki/api/auth.md`).

## Правила для агентов

Общий порядок работы — [rules/agents](../../rules/agents.ru.md). Для отметок дополнительно:

1. Отметка нужна для правки, которая займёт заметное время или идёт параллельно с другими агентами. Отметку на один шаг другие агенты не успеют увидеть.
2. Нашёл чужую действующую отметку на тех же путях — не начинать параллельно: написать её автору (`note` или `question`) или выбрать другую задачу.
3. Отметка — не место для обсуждения: всё содержательное — в обсуждениях.

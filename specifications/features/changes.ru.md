# Функция «Изменения»

**Ключ:** `changes` · **Статус:** черновик

Отвечает агенту на вопрос: **что изменилось в документации проекта с моего последнего просмотра?** Нужна, когда агент начинает новую сессию, а также получателю межпроектного контракта — узнать, что контракт поменялся.

Изменения wiki берутся из **истории хаба**, изменения docs — из **истории репозитория источника** (локального клона). Хаб хранит только **отметку просмотра** каждого агента. Выгрузка docs истории не содержит.

## Подключение

```yaml
projects:
  portal:
    features:
      changes: { enabled: true }
```

## Модель

**Отметка просмотра** — последние коммиты хаба и каждого источника, до которых агент видел изменения. Файл `projects/<id>/changes/<агент>.yaml`, пишет только сам агент. Схема — [schemas/changes](../../schemas/changes.ru.md).

**Изменения** — коммиты после отметки, затрагивающие документы, доступные агенту (с учётом `members.<агент>.paths`).

## Операции

| Операция | Что делает |
|---|---|
| показать | Список коммитов после отметки и изменённых в них документов (по доступным путям) |
| показать diff | То же с изменениями текста |
| отметить просмотренным | Записать в отметку текущий последний коммит ветки |

Без отметки показываются последние 20 коммитов по доступным путям (*предложение*) с пометкой, что отметки нет, или изменения с указанного коммита. Окно по дням не подходит: документация может не меняться неделями, и новый агент увидел бы «изменений нет».

Команды — `doc-hub changes [--since <sha>] [--diff]` и `doc-hub changes ack [<sha>]`, см. [cli-contract](../cli-contract.ru.md#изменения).

## Без клона

Если у агента есть только выгрузка docs, без клона репозитория:

- `commit` паспорта отличается от отметки — значит, документация изменилась;
- список изменённых файлов и diff получить нельзя: в выгрузке нет истории. Для них нужен доступ к репозиторию.

## Связь с обсуждениями

- В выводе изменений полезно показывать обсуждения со статусом `applied`, у которых `commit` попадает в диапазон: «почему изменилось».
- Если изменение касается других агентов, автор правки создаёт `note` (см. [discussions](discussions.ru.md#правила-для-агентов)). `changes` не заменяет уведомление, а страхует, если его забыли.

## Ограничения

- Агент без клона источника не видит изменений docs этого источника. Изменения wiki видны всем, у кого есть клон хаба.

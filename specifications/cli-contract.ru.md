# Интерфейс эталонной реализации `doc-hub`

> **Не часть протокола.** Это команды эталонной реализации: своя реализация может устроить интерфейс иначе, см. [protocol](protocol.ru.md). Первая версия реализована в репозитории `cli` (Python): рабочий цикл агента. Команды администратора (`init`, `project`, `area`, `feature`, `agent`, `member`) не реализованы, конфигурация правится вручную.

Исполняемый файл — `doc-hub`.

- **Хаб** — из `.doc-hub.json` текущего репозитория или `DOC_HUB_PATH`; параметр `--hub`.
- **Агент** — `--agent` или `DOC_HUB_AGENT`, см. [access](access.ru.md#идентичность). Без агента — только чтение.
- **Проект** — параметр `--project`, иначе первый элемент `projects`, затем `access` манифеста, иначе единственный проект, где агент — участник.

Агент запускается в репозитории своего проекта, а не в хабе.

## Общие требования

- Вывод — текст; с `--json` — JSON для агентов.
- Код возврата `0` — успех; не `0` — ошибка с понятным сообщением (нет прав, нет проекта, неверный формат, агент не определён).
- Проверка прав, ограничений путями и схем.
- Записывающие команды: `git pull --rebase` → запись → `commit` только своих файлов от имени агента → `push` (если есть origin), см. [hub-storage](hub-storage.ru.md#синхронизация-между-машинами).
- Внешнюю документацию CLI не правит: `docs sync` только выгружает её в хаб.

## Хаб и проекты

| Команда | Что делает | Кто |
|---|---|---|
| `doc-hub init <путь>` | Создаёт хранилище хаба | администратор |
| `doc-hub project register <id>` | Регистрирует проект | администратор |
| `doc-hub project list` | Проекты, доступные агенту, его роли и пути | все |
| `doc-hub project show [<id>]` | Пути, зоны, владельцы, участники, функции | участники |
| `doc-hub area set <путь> --owners a,b` | Зона и владельцы | администратор |
| `doc-hub feature enable\|disable <функция>` | Включить / отключить функцию | администратор |
| `doc-hub agent add <имя> --description …` | Добавить агента | администратор |
| `doc-hub member set <агент> --role participant\|reader [--paths …]` / `member remove` | Участник проекта | администратор |
| `doc-hub whoami` | Имя агента, хаб, проекты и роли | все |
| `doc-hub validate` | Проверка конфигурации и данных по схемам | все |

## Wiki

| Команда | Что делает | Кто |
|---|---|---|
| `doc-hub wiki list [<путь>]` | Документы в доступных путях | все |
| `doc-hub wiki read <путь\|проект:путь[@коммит]>` | Содержимое и коммит хаба | все |
| `doc-hub wiki search <запрос>` | Простой текстовый поиск | все |
| `doc-hub wiki owner <путь>` | Зона и владельцы документа | все |
| `doc-hub wiki write <путь> --message … [--file …] [--base <коммит>]` | Записать документ; текст из файла или stdin; `--base` — отказ, если файл менялся | владелец зоны |
| `doc-hub wiki move <откуда> <куда> --message …` | Переместить | владелец зоны |
| `doc-hub wiki delete <путь> --message …` | Удалить | владелец зоны |

## Docs

| Команда | Что делает |
|---|---|
| `doc-hub docs sync [<папка>…] [--ref <ссылка>]` | Выгрузить источники, см. [docs-sources](docs-sources.ru.md). В git хаба не коммитит |
| `doc-hub docs status [<папка>…]` | Коммит выгрузки, время, отставание, неотправленный коммит, незакоммиченные изменения |
| `doc-hub docs list [<путь>]` | Документы в доступных путях |
| `doc-hub docs read <путь\|проект:путь[@коммит]>` | Содержимое: из выгрузки, иначе из клона; в выводе — коммит |
| `doc-hub docs search <запрос>` | Простой текстовый поиск |

## Обсуждения

| Команда | Кто |
|---|---|
| `doc-hub discussion list [--status …] [--kind …] [--to <агент>] [--ref <путь>] [--mine]` | все с доступом |
| `doc-hub discussion show <обсуждение>` | все с доступом |
| `doc-hub discussion create --kind question\|proposal\|note --title … [--to a,b] [--ref проект:путь] --message <текст\|->` | `participant` |
| `doc-hub discussion reply <обсуждение> --message <текст\|->` | `participant` |
| `doc-hub discussion answered <обсуждение> --outcome …` | автор, владелец зоны |
| `doc-hub discussion accept\|reject <обсуждение> --outcome …` | владелец зоны |
| `doc-hub discussion apply <обсуждение> --changes путь,… --commit <sha>` | владелец зоны |
| `doc-hub discussion close <обсуждение> --outcome …` | автор, адресат (`note`), владелец зоны |
| `doc-hub discussion search <запрос>` | все с доступом — поиск по итогам и темам |
| `doc-hub inbox` — обсуждения, где нужна реакция: агент адресат, автор с новым ответом, владелец зоны с открытым или принятым обсуждением | все |

`<обсуждение>` — имя файла без расширения (`2026-11-06-error-format`) или `uid`. `--message -` читает текст из stdin.

## Изменения

| Команда | Что делает |
|---|---|
| `doc-hub changes [--since <sha>] [--diff]` | Изменения wiki и docs после отметки агента |
| `doc-hub changes ack` | Обновить отметку просмотра: wiki и все docs |

## Отметки работы

| Команда | Что делает |
|---|---|
| `doc-hub claim add <пути…> --topic … [--for 4h] [--discussion …]` | Поставить; при пересечении — предупреждение и отказ без `--force` |
| `doc-hub claim list [--path …]` | Действующие отметки |
| `doc-hub claim check <пути…>` | Есть ли пересечения |
| `doc-hub claim extend <отметка> --for 2h` / `claim release <отметка>` | Продлить / снять |

## Сводка для начала сессии

`doc-hub status` — одна команда для агента в начале сессии: кто я, входящие (`inbox`), изменения с последнего просмотра, действующие отметки по проекту, отставание выгрузок docs.

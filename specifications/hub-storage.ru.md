# Хранилище хаба

Хаб — git-репозиторий с конфигурацией, wiki проектов и данными функций. Подключённая внешняя документация лежит рядом, но в git не попадает. Он же — Obsidian-vault, см. [obsidian](../rules/obsidian.ru.md).

## Структура

```
<hub>/
├── README.md                    # описание хаба для людей
├── AGENTS.md, AGENTS.ru.md      # вход для ИИ-агентов и его русская версия (шаблоны — templates/hub-AGENTS*.md)
├── OBSIDIAN.md, OBSIDIAN.ru.md  # памятка для работы в Obsidian (шаблоны — templates/hub-obsidian*.md)
├── .gitignore                   # .doc-hub/config.local.yaml, .obsidian/workspace.json, projects/*/docs/ (шаблон — templates/hub-gitignore)
├── .doc-hub/
│   ├── config.yaml              # проекты, зоны, агенты, роли, функции (в git)
│   └── config.local.yaml        # пути к клонам репозиториев на этой машине (не в git)
├── .obsidian/                   # настройки Obsidian
├── templates/                   # шаблоны для плагина «Шаблоны»
└── projects/
    └── <id>/
        ├── wiki/                     # своя документация, в git
        ├── docs/                     # внешняя, не в git
        │   └── <папка>/
        │       └── .source.yaml      # паспорт
        ├── discussions/
        │   └── <YYYY-MM-DD-slug>.md
        ├── changes/
        │   └── <агент>.yaml          # отметка просмотра
        ├── claims/
        │   └── <агент>-<slug>.md     # отметка работы
        └── board/
            └── <slug>.md             # карточка
```

Схемы файлов: [discussion](../schemas/discussion.ru.md), [changes](../schemas/changes.ru.md), [claim](../schemas/claim.ru.md), [card](../schemas/card.ru.md), [docs-source](../schemas/docs-source.ru.md).

## Кто меняет какой файл

Права на запись — [access](access.ru.md#политика-записи). По файлам:

| Файл | Кто меняет |
|---|---|
| `discussions/<slug>.md` | участники дописывают сообщения; статус меняют по правилам функции |
| `changes/<агент>.yaml` | сам агент |
| `claims/<агент>-<slug>.md` | сам агент; истёкшую отметку может удалить любой участник |
| `board/<slug>.md` | участники по правилам функции |
| `.doc-hub/config.yaml` | администратор хаба |
| `wiki/…` | владелец зоны |
| `docs/<папка>/…` | только операция выгрузки; не в git |

Отметки разложены по файлам авторов и не конфликтуют при слиянии. Обсуждения, карточки и wiki могут столкнуться, см. [столкновения записи](#столкновения-записи).

## Синхронизация между машинами

Хаб — обычный git-репозиторий с общим удалённым репозиторием (origin). На каждой машине — свой клон.

Порядок записи для любой реализации:

1. Перед чтением и записью — `git pull --rebase`.
2. После записи — `git add` и `commit` только своих файлов. Сообщение — `<агент>: <действие> <объект>`, автор коммита — имя агента.
3. `git push`. Отказ — `pull --rebase` и повтор. Origin недоступен — локальный коммит сохраняется и отправляется позже, запись не отменяется.

Люди в Obsidian — плагин Git (автоматический pull/push).

**Хаб без origin.** Допустимый режим для одной машины: `pull` и `push` пропускаются.

### Столкновения записи

Если `rebase` завершился конфликтом: прервать его, отменить свой коммит, обновить хаб.

- **Обсуждение:** дописать сообщение заново поверх свежей версии. Перед сменой статуса снова проверить, что переход допустим.
- **Карточка:** перечитать её, снова проверить, что переход допустим, и повторить запись.
- **Wiki:** отказать в записи и сообщить о конфликте, чтобы автор перечитал документ.

Чужие изменения не затираются. Человек в Obsidian разрешает конфликт вручную.

Папки функций создаются при первой записи.

Сервис вместо git — реализация уровня 3, вне Core, см. [levels](../concepts/levels.ru.md).

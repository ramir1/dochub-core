# Внешняя документация (docs)

**Docs** — подключённая к проекту внешняя документация **только для чтения**. Источник — репозиторий, хаб лишь выгружает её для чтения. Своя документация — [wiki](wiki.ru.md).

## Подключение

Источник подключается в конфигурации проекта: ключ — имя папки, значение — откуда брать.

```yaml
projects:
  portal:
    docs:
      tech:
        repository: git@github.com:example/portal.git
        branch: main
        path: docs
```

Содержимое `path` кладётся прямо в папку: `docs` репозитория попадает в `projects/portal/docs/tech/`. Источников может быть несколько. Путь к клону на этой машине — `projects.<id>.docs.<папка>.local_path` в `config.local.yaml`.

## Свойства

- **Только для чтения.** Выгрузку не редактируют: правка пропадёт при следующей выгрузке. Править — в репозитории источника.
- **Не в git хаба.** Это источники для чтения, их история — в своих репозиториях. `projects/*/docs/` в `.gitignore` хаба, на каждой машине своя выгрузка.
- **С указанием коммита.** В папке лежит паспорт `.source.yaml`, см. [schemas/docs-source](../schemas/docs-source.ru.md).
- **Без требований.** Хаб ничего не требует от внешней документации и не меняет файлы; действуют правила её репозитория.

Агент без доступа к репозиторию источника docs не получит. Всё, что ему нужно читать, кладётся в wiki.

## Обновление

Выгрузка делается для всех источников проекта или для выбранных папок:

1. Выполняет `git fetch` в клоне, если у него есть origin.
2. Берёт **зафиксированный коммит** локальной ветки `branch` или явно указанной ссылки. Рабочая копия не используется: незакоммиченные правки в выгрузку не попадают. Локальная ветка выбрана потому, что документация может быть закоммичена, но ещё не отправлена.
3. Выгружает `path` во временную папку и заменяет ею `projects/<id>/docs/<папка>/`. Если пути в коммите нет, старая выгрузка остаётся.
4. Записывает паспорт. В git хаба ничего не коммитит.

Агенту с ограничением путями выгружаются только разрешённые пути. На общей машине такая выгрузка сузится для всех, поэтому обновлять её лучше агенту без ограничений.

Обновление только явное: запуск в начале сессии или из git-hook настраивает человек.

**Предупреждения** при выгрузке и показе её состояния: выгрузка отстаёт от ветки; коммит не отправлен в origin; в репозитории есть незакоммиченные изменения источника; папка не в `.gitignore` хаба.

## Чтение

Реализация читает docs из выгрузки, а если её нет — из коммита в клоне, и показывает источник и коммит. Ссылка `проект:путь@коммит` читается из git репозитория.

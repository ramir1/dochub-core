# Внешняя документация (docs)

**Docs** — подключённая к проекту внешняя документация **только для чтения**. Хаб её не правит и лишь выгружает для чтения. Своя документация — [wiki](wiki.ru.md).

## Виды источников

| | Локальная папка | Репозиторий |
|---|---|---|
| Когда | По умолчанию: документация лежит на этой машине | Явно: нужен зафиксированный коммит или другой репозиторий |
| Что берётся | Файлы как есть, вместе с незакоммиченными | Зафиксированный коммит локальной ветки клона |
| Нужен git | Нет | Да |
| Коммит в паспорте | Нет | Есть |
| История изменений | Нет | Есть |

## Подключение

Источник подключается в конфигурации проекта: ключ — имя папки, значение — откуда брать. Есть `repository` — источник из репозитория, нет — локальная папка.

```yaml
projects:
  portal:
    docs:
      tech:                                  # локальная папка
        path: packages/ramirko/postcode/docs
      api:                                   # репозиторий
        repository: git@github.com:example/portal.git
        branch: main
        path: docs
```

Содержимое `path` кладётся прямо в папку: `docs/tech/` получает файлы из `path`. Источников может быть несколько. Корень на этой машине — `projects.<id>.docs.<папка>.local_path` в `config.local.yaml`: корень проекта для локальной папки, клон для репозитория. `path` указывается от этого корня, поэтому одинаков на всех машинах.

## Свойства

- **Только для чтения.** Выгрузку не редактируют: правка пропадёт при следующей выгрузке. Править — в источнике.
- **Не в git хаба.** Это источники для чтения. `projects/*/docs/` в `.gitignore` хаба, на каждой машине своя выгрузка.
- **С паспортом.** В папке лежит паспорт `.source.yaml`, см. [schemas/docs-source](../schemas/docs-source.ru.md).
- **Без требований.** Хаб ничего не требует от внешней документации и не меняет файлы.

Агент без доступа к источнику docs не получит. Всё, что ему нужно читать, кладётся в wiki.

## Обновление

**Локальная папка.** Выгрузка копирует файлы папки как есть в `projects/<id>/docs/<папка>/` и записывает паспорт. Папку `.git` не копирует. Если папки на этой машине нет, старая выгрузка остаётся.

**Репозиторий.** Выгрузка делается для всех источников проекта или для выбранных папок:

1. Выполняет `git fetch` в клоне, если у него есть origin. Недоступный origin не мешает выгрузке.
2. Берёт **зафиксированный коммит** локальной ветки `branch` или явно указанной ссылки. Рабочая копия не используется. Локальная ветка выбрана потому, что документация может быть закоммичена, но ещё не отправлена.
3. Выгружает `path` во временную папку и заменяет ею `projects/<id>/docs/<папка>/`. Если пути в коммите нет, старая выгрузка остаётся.
4. Записывает паспорт. В git хаба ничего не коммитит.

Агенту с ограничением путями выгружаются только разрешённые пути. На общей машине такая выгрузка сузится для всех, поэтому обновлять её лучше агенту без ограничений.

Обновление только явное: запуск в начале сессии или из git-hook настраивает человек.

**Предупреждения** при выгрузке и показе её состояния:

- локальная папка: файлы отличаются от выгрузки;
- репозиторий: выгрузка отстаёт от ветки; коммит не отправлен в origin; в репозитории есть незакоммиченные изменения источника;
- любой источник: папка не в `.gitignore` хаба.

## Чтение

**Локальная папка** читается напрямую, поэтому данные всегда свежие. Если папки на этой машине нет — из выгрузки.

**Репозиторий** читается из выгрузки, а если её нет — из коммита в клоне. Реализация показывает источник и коммит. Ссылка `проект:путь@коммит` читается из git репозитория; у локальной папки коммитов нет.

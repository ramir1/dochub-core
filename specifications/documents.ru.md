# Документы

## Где документы

Документ — Markdown-файл в [wiki](wiki.ru.md) или в подключённых [docs](docs-sources.ru.md) проекта.

## Идентификация

Документ указывается как **проект + путь в проекте**: `wiki/…` или `docs/<папка>/…`:

```
portal:wiki/mobile-app/09-comments.md
```

При необходимости — с коммитом, на котором документ имел в виду автор:

```
portal:wiki/mobile-app/09-comments.md@4f2a9c1
```

В тексте сообщений внутри одного проекта проект можно не указывать.

Коммит — из хаба для wiki, из репозитория источника для docs. Коммит должен быть отправлен в origin, иначе на других машинах ссылка не откроется. Документ мог измениться после указанного коммита: актуальное читать в документации.

## uid

- В документацию хаб **не добавляет** `uid` и другие поля.
- В данных хаба `uid` (ULID) есть у обсуждений. Его ставит создатель: реализация, агент или человек командой плагина Obsidian (уровни 1–2). Подробнее — [discussion](../schemas/discussion.ru.md).
- `uid` не меняют и не копируют.

## Ссылки

- В wiki — относительные Markdown-ссылки, см. [default-rules](../rules/default-rules.ru.md#требования-к-wiki). В docs — по правилам их репозитория.
- Из данных хаба на документы — в полях `refs` и `changes` в формате `проект:путь`; в тексте сообщений — так же, в `моноширинном` шрифте. Поле `paths` отметки работы хранит виртуальные пути без проекта: файл отметки уже лежит в проекте.
- Wiki-ссылки Obsidian (`[[...]]`) в данных хаба не используются: вне Obsidian они не работают.
- Пути файлов на диске в данных хаба не используются.

## Перемещение документов

Документ wiki переносит владелец зоны, ссылки на него внутри wiki сверяет проверка данных. Ссылки из данных хаба (`refs` старых обсуждений) сами не обновляются: обсуждение отражает состояние на момент своего создания. Документ docs переносят в его репозитории.

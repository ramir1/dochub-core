# Документы

## Где документы

Документ — Markdown-файл в [wiki](wiki.ru.md) или в подключённых [docs](docs-sources.ru.md) проекта.

## Идентификация

Документ указывается как **проект + путь в проекте**: `wiki/…` или `docs/<папка>/…`:

```
portal:wiki/mobile-app/09-comments.md
```

При необходимости — с коммитом, на котором документ имел в виду автор:

```
portal:wiki/mobile-app/09-comments.md@4f2a9c1
```

Внутри одного проекта проект можно не указывать.

Коммит — из хаба для wiki, из репозитория источника для docs. Коммит должен быть отправлен в origin, иначе на других машинах ссылка не откроется. `doc-hub discussion show` предупреждает, если документ менялся после указанного коммита.

## uid

- В документацию хаб **не добавляет** `uid` и другие поля.
- В данных хаба `uid` (ULID) есть у обсуждений. Его ставит создатель: CLI, агент или человек командой плагина Obsidian. Подробнее — [discussion](../schemas/discussion.ru.md).
- `uid` не меняют и не копируют.

## Ссылки

- В wiki — относительные Markdown-ссылки, см. [default-rules](../rules/default-rules.ru.md#требования-к-wiki). В docs — по правилам их репозитория.
- Из данных хаба на документы — в полях (`refs`, `changes`, `paths`) в формате `проект:путь`; в тексте сообщений — так же, в `моноширинном` шрифте.
- Wiki-ссылки Obsidian (`[[...]]`) в данных хаба не используются: вне Obsidian они не работают.
- Ссылки из данных хаба — только в формате `проект:путь`, а не пути файлов на диске.

## Перемещение документов

Документ wiki переносят командой `doc-hub wiki move`, ссылки на него внутри wiki проверяет `doc-hub validate`. Ссылки из данных хаба (`refs` старых обсуждений) сами не обновляются: обсуждение отражает состояние на момент своего создания. Документ docs переносят в его репозитории.

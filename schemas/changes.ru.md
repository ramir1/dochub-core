# Схема отметки просмотра изменений

Спецификация — [changes](../specifications/features/changes.ru.md).

Файл `projects/<id>/changes/<агент>.yaml`, пишет только сам агент.

| Поле | Тип | Обяз. | Описание |
|---|---|:-:|---|
| `agent` | строка | да | Имя агента; совпадает с именем файла |
| `wiki` | строка | да | Последний просмотренный коммит хаба (полный SHA) |
| `docs` | словарь | нет | Папка источника → последний просмотренный коммит |
| `seen_at` | дата-время | да | Когда отмечено, ISO 8601 в UTC |

```yaml
agent: mobile-dev
seen_at: 2026-11-06T11:00:00Z
wiki: 7c1e0b4d2f9a8e6c5b3a1d0f9e8d7c6b5a4f3e21
docs:
  tech: 4f2a9c1d8e7b6a5f4e3d2c1b0a9f8e7d6c5b4a39
```

Формат YAML выбран потому, что файл служебный и читается программами. В Obsidian `.yaml` по умолчанию не показывается — это нормально.

# Работа через Obsidian

Obsidian — интерфейс хаба для людей: хаб открывается как vault, один на все проекты. В нём видны и правятся wiki, видны обсуждения, отметки работы и внешняя документация.

## Настройка vault

1. Клонировать хаб: `git clone <origin хаба> ~/projects/dochub.ws`. Открыть папку в Obsidian: «Открыть папку как хранилище».
2. **Файлы и ссылки:**
   - «Автоматически обновлять внутренние ссылки» — вкл.;
   - «Использовать [[Wiki-ссылки]]» — **выкл.**;
   - «Формат новых ссылок» — относительный путь.
3. **Основные плагины:** «Шаблоны» (папка — `templates`), «Свойства», «Поиск», «Обратные ссылки».
4. **Сторонние плагины:**
   - **Git** (obsidian-git) — автоматический pull при открытии и push после изменений; сообщение коммита — с именем человека-агента (`ramir: …`);
   - **Note UID Generator** — для `uid` обсуждений, см. ниже.

## Note UID Generator

Файлы хаба пишут разные авторы на разных машинах. Автоматическая генерация `uid` изменила бы чужой файл при открытии, поэтому она **выключена**; `uid` ставится вручную командой плагина в своём новом файле обсуждения.

| Ключ (`.obsidian/plugins/note_uid_generator/data.json`) | Значение |
|---|---|
| `uidKey` | `uid` |
| `uidGenerator` | `ulid` |
| `autoGenerateUid` | `false` |
| `duplicateUidCheck` | `notify` |

В текущем `dochub.ws` автогенерация включена для папки `hub`, которой нет. Привести к таблице — не выполнено.

## Wiki

Своя документация — `projects/<id>/wiki/`. Правьте прямо в Obsidian, плагин Git отправит изменения. Правьте документы своей зоны, требования — [default-rules](default-rules.ru.md#требования-к-wiki). Другая машина могла изменить тот же файл: при конфликте плагин Git покажет его, разрешается как обычный конфликт git.

## Внешняя документация

`projects/<id>/docs/<папка>/` — только чтение, см. [docs-sources](../specifications/docs-sources.ru.md).

- **Обновить** — `doc-hub docs sync`.
- **Не редактировать.** Правка пропадёт при следующем обновлении и в репозиторий не попадёт.
- **Не в git.** Папка в `.gitignore` хаба (шаблон — [hub-gitignore](../templates/hub-gitignore)), плагин Git её не отправляет.
- **Свежесть.** Коммит — в `.source.yaml`. В Obsidian этот файл скрыт (имя с точкой): смотрите `doc-hub docs status`.
- **Поиск:** `path:"projects/portal/wiki"` или `path:"projects/portal/docs"`.
- Автогенерация `uid` должна быть выключена (см. выше), иначе плагин допишет `uid` в документы.

## Обсуждения

- **Читать:** `projects/<id>/discussions/<файл>.md` — весь разговор в одном документе.
- **Открытые обсуждения:** поиск `path:"projects/portal/discussions" [status:open]`.
- **Мои входящие:** поиск `[to:ramir]`.
- **Создать:** новый файл `YYYY-MM-DD-slug.md` из шаблона `templates/discussion.md`, команда плагина «сгенерировать UID».
- **Ответить:** дописать в конец файла пустую строку, разделитель `---`, метку `[YYYY-MM-DDTHH:MM:SSZ <агент>]` и текст. Чужие сообщения не менять.
- Время в шаблонах — местное, а схема требует UTC: при создании поправить время и смещение (или указать местное время с `Z`, заменив вручную). Это неудобство этапа 1.

## Отметки работы

`projects/<id>/claims/` — кто над чем работает. Человек тоже может поставить отметку из шаблона `templates/claim.md`.

## Шаблоны

Скопировать из Core в `templates/` хаба, убрав суффикс языка: [discussion](../templates/discussion.ru.md) → `discussion.md`, [claim](../templates/claim.ru.md) → `claim.md`.

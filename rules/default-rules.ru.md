# Правила ведения документации

## Требования к wiki

Обязательны для [wiki](../specifications/wiki.ru.md): хаб здесь источник истины.

1. **Своя зона.** Править документы своей зоны (см. [projects](../specifications/projects.ru.md#зоны)). Чужая зона — предложение владельцу через обсуждение.
2. **Ссылки.** Относительные Markdown-ссылки, ведут на существующие файлы. Сверяются при проверке данных, см. [protocol](../specifications/protocol.ru.md#проверка-данных).
3. **Имена** — по [naming](naming.ru.md).
4. **Один документ — одна тема.** Новую тему — в новый файл со ссылкой из оглавления, если оно есть.
5. **Сохранять структуру.** Не переименовывать и не перемещать файлы без необходимости. Перенёс — обновить все ссылки.
6. **Следовать принятому в документе:** стиль, язык, нумерация разделов, формат таблиц и примеров.
7. **Достоверность** — см. [writing](writing.ru.md).
8. **Дата актуальности.** Есть строка версии или даты («Актуально на…») — обновлять при содержательной правке.
9. **Сообщить.** Правка касается других агентов (контракт, формат, поведение) — `note` адресатам.

Frontmatter и `uid` пока не требуются (*предложение*).

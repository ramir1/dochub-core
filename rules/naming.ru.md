# Именование

## Файлы и папки Core и хаба

- Латиница в нижнем регистре, цифры, дефис: **kebab-case** (`project-manifest.ru.md`, `use-cases.ru.md`).
- Без пробелов, кириллицы, подчёркиваний и двойных расширений (`README.md.md` — ошибка).
- Порядковые номера — в начале: `01-quick-start.md`, `02-domains.md`.
- Служебные файлы — в верхнем регистре: `README`, `AGENTS`.

## Языковой суффикс

Документы Core и хаба, у которых есть или будут переводы, имеют суффикс языка перед расширением:

```
overview.ru.md    # русская версия
overview.en.md    # английская версия
```

Коды языков — ISO 639-1 (`ru`, `en`). Подробнее — [translation](translation.ru.md).

Исключения:

- В хабе `README.md` и `AGENTS.md` в корне — без суффикса: их ищут по точному имени инструменты и агенты. В шаблоне Core такой файл называется с суффиксом (`templates/hub-AGENTS.ru.md`) и копируется в хаб без него.
- Скилы — `skills/<имя>/SKILL.md`: имя файла задаёт формат скилов.
- Документация проектов — по правилам самого проекта; существующие файлы ради суффикса не переименовываются.

## Идентификаторы

Идентификаторы хаба, проектов, агентов, ключи функций: `^[a-z0-9][a-z0-9-]*$` (`portal`, `ramir-claude-backend`, `discussions`).

## Агенты

Агент — роль в работе, а не программа. Рекомендуемое имя: `<человек>-<инструмент>-<зона>`:

- `ramir-claude-backend`, `ramir-codex-frontend`, `ramir-claude-tests`;
- человек — просто имя: `ramir`;
- агент чужой команды — по проекту: `mobile-dev`.

## Данные хаба

| Что | Имя |
|---|---|
| Документ wiki | `projects/<id>/wiki/…`, имя файла — как принято в проекте, латиницей в kebab-case |
| Папка внешней документации | `projects/<id>/docs/<папка>/`; папка — ключ в `docs` конфигурации |
| Обсуждение | `discussions/YYYY-MM-DD-<slug>.md` |
| Отметка просмотра | `changes/<агент>.yaml` |
| Отметка работы | `claims/<агент>-<slug>.md` |

`slug` — тема латиницей в kebab-case, 2–5 слов. Подробно — [schemas/](../schemas/).
